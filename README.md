 Childhood Anemia in Nigeria (2018 NDHS)
 
Capstone data analysis project by Aishatu Abubakar.

Research question
Which socioeconomic factors, household wealth and mother's education, show the strongest differences in childhood anemia severity, and do these patterns differ between urban and rural areas?

 Data : 2018 Nigeria Demographic and Health Survey (NDHS). Analysis population: 10,182 children aged 0–59 months with recorded child anemia measurements.

 Tools and method
Google Sheets; descriptive cross-tabulation with pivot tables. No significance testing; findings are descriptive and do not establish causation.

 Key finding 
 Moderate/severe anemia: 24.0% (richest) vs 54.0% (poorest households); 20.2% (higher education) vs 50.3% (no education); 34.7% (urban) vs 46.2% (rural).
